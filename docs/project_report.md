# Project Report Outline

## Aim
To build an integrated Data Warehouse and Data Mining system for analyzing and predicting student placement outcomes.

## Dataset
15,000 student records and 26 original columns. Target: `placement_prediction` (1 placed, 0 not placed).

## Methodology
1. Validate and preprocess data.
2. Build a star schema and SQLite warehouse.
3. Perform OLAP analysis.
4. Mine correlations, mutual information and feature importance.
5. Train Decision Tree, Random Forest and Naive Bayes classifiers.
6. Run SLR/MLR for numerical prediction.
7. Perform K-Means and Agglomerative clustering.
8. Compare models using measurable evaluation metrics.

## Conclusion
The dashboard integrates descriptive warehouse analysis, OLAP, data mining, supervised learning and unsupervised learning in one interactive application.
